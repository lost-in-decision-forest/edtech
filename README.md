# Audio-Friendly EdTech
This project’s purpose is to provide curation and structure for publicly available, audio-friendly educational content, and to make it easier to use. 

For now, it is mostly scoped to content available on Spotify. One still needs an account and a subscription to make it usable. While Spotify supports video podcasts, the goal of this effort is to find content that does not require either your eyes or hands engaged so that they can be doing something else, like driving or gardening.

There is a long way to go, and contributions are welcome and appreciated. Please refer to CONTRIBUTING.md for details.
